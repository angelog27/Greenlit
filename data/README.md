# Game data

Everything the game knows about genres, people and the calendar. Each file has one record per line with the columns lined up, so you can scan a file like a table or search it for an id.

JSON can't hold comments, so this page explains what the files and fields mean. All fees, star ratings, skills and bonuses are invented game numbers.

## Finding someone

- **An actor or director:** search for their id (`"dicaprio"`) or name in `actors.json` / `directors.json`.
- **Who a director has worked with:** search `loyal.json` for `"director": "nolan"`. All of a director's rows sit together.
- **An actor's chemistry pairs:** search `chem.json` for their id. A pair is listed under whichever of the two actors comes first in `actors.json`, so check both the `a` and `b` columns.

## Files and how they are sorted

| File | What's in it | Sorted by |
| --- | --- | --- |
| `actors.json` | The cast pool | Star power (high to low), then fee, then name |
| `directors.json` | The director pool | Skill (high to low), then fee, then name |
| `loyal.json` | Reunion bonuses: a director and an actor who made real films together | Director (same order as `directors.json`), then biggest bonus |
| `chem.json` | Chemistry bonuses: two actors who shared real films | First actor (same order as `actors.json`), then biggest bonus |
| `genres.json` | 8 plain genres, then 5 blends | **Fixed order, don't re-sort** |
| `windows.json` | Release seasons | **Fixed order, don't re-sort** |
| `slate.json` | Real upcoming releases (Hard mode) | Release date |
| `plots.json` | Three story pitches per genre | **Fixed order, don't re-sort** |
| `images.json` | TMDB photo and poster paths | Generated by `tools/fetch_images.mjs` |
| `campaign.json` | Campaign progression: bank, caps, tiers, unlock ladder, passes | Hand-edited, any order |
| `achievements.json` | Campaign gates (names for the ladder steps) and badges | Hand-edited; badge order is the shelf order |

**Why some files are fixed:** each day's puzzle is rolled from the date. The roll walks `genres.json` and `windows.json` from top to bottom, and picks each genre's story by its position in `plots.json`. Re-sorting those files would change every day's heat, budget, rival week and stories. You can reorder actors, directors, `loyal` and `chem` freely, because every person gets their own seed for the daily shortlists.

## After editing

Run this from the repo root to put everything back in sorted, aligned form:

```sh
node tools/format_data.mjs
```

It only sorts and lays out records. It never adds, removes or changes them. Then run the tests (`node --test tests/js/*.test.mjs`), which check that every id resolves.

## Fields

### actors.json

| Field | Meaning |
| --- | --- |
| `id` | Short unique key used by every other file |
| `name` | Display name |
| `s` | `m` or `f`. Each role's shortlist has 3 men and 3 women |
| `star` | Star power, 5 to 10. Each star adds 3% to gross on Easy (lead 4%, supporting 2%, antagonist 2.5% on Medium and Hard) |
| `fee` | Cost in $M, 6 to 30 |
| `g` | Genres the actor fits: +8% each on Easy (lead +10%, supporting +5%, antagonist +6% on Medium and Hard). Matches a blend if it lists either half |
| `tone` | Tones the actor plays. A role or story that asks for one of them adds a bonus |
| `known` | Real films, shown in the game |

### directors.json

| Field | Meaning |
| --- | --- |
| `id`, `name` | As for actors |
| `skill` | Gross multiplier, ×1.00 to ×1.25 |
| `fee` | Cost in $M, 12 to 36 |
| `spec` | Specialty genres: +15% when the film's genre matches |
| `tone` | Tones they direct. +5% for each one the story shares |
| `note`, `known` | One-line description and real films, shown in the game |

### loyal.json and chem.json

| Field | Meaning |
| --- | --- |
| `director`, `actor` (loyal) | The two people (ids) |
| `a`, `b` (chem) | The two actors (ids). Order doesn't matter |
| `bonus` | Added to the synergy total: 0.08 to 0.40 for reunions, 0.08 to 0.15 for chemistry |
| `films` | The real films they made together, shown in the game |

### Tones

`gritty`, `heartfelt`, `funny`, `epic`, `eerie`, `stylish`. They are used by actors, directors and the stories in `plots.json`.

### genres.json

`base` is the starting gross and `cost` the production cost in $M. A blend has `mix: [half, half]`: people and rival films match it if they match either half, and its heat and window fit are the average of the two halves.

### windows.json

`cost` is marketing in $M and `base` is the season's gross multiplier. `g` holds genre multipliers for that season (a missing genre counts as ×1). `hardOnly` seasons appear only in Hard mode, where the month of the release date picks the season.

### plots.json

Six pitches per genre. `tones` are the tones the story wants, `win` the seasons it suits, and `lead`, `side`, `anta` describe each part (`r`) and the tone it needs (`t`). A pitch with `from` (a date) only joins the draw from that UTC day, so adding stories never changes a day that has already been played: **append new pitches at the end of a genre's list with a `from` date at least a day ahead, and deploy the functions before that date.**

### slate.json

`date` is the release date. `genre` is our nearest plain genre. `strength` (1 to 10) is how hard the film competes. A film in your genre on your weekend costs the most.

## Campaign files

The campaign (solo career mode) reads two files. The server enforces them; the page only shows them. Edit, then run `node tools/campaign_report.mjs` (tier coverage) and `node tools/campaign_sim.mjs` (pacing) before deploying. Both are copied into `functions/gen/` by `tools/build_functions.mjs`, and changing them never changes the roster version of the daily boards.

### campaign.json

| Field | Meaning |
| --- | --- |
| `start.bank` | Bank of a new studio, $M |
| `start.floor` | The bank never stays below this: a film or fee that takes it lower triggers a bailout back to the floor (counted on the studio) |
| `caps` | Budget cap per tier. A project's budget is the bank, clamped between the floor and the cap of the highest tier unlocked (cast or directors) |
| `tiers.order` | Tier names, lowest first |
| `tiers.actorMinStar` | Minimum `star` for each tier. An actor's tier is the highest whose minimum they meet |
| `tiers.directorMinSkill` | Minimum `skill` for each director tier |
| `ladder` | Unlock steps. `at` is the lifetime profit ($M) that opens the step; `actors`/`directors` set the highest tier on the shortlists from then on; `genres` become playable; `hard: true` lets the player switch any project to real release dates. Lifetime profit only counts profitable films, so it never goes down |
| `boardGoal` | The ladder step whose film count ranks the campaign board |
| `trainingFilms` | How many films run with Easy visibility before projects switch to Medium (hidden numbers) |
| `recentFilms` | How many recent films the studio doc keeps for the HQ |
| `shortlist` | `perGender` per role (3 men, 3 women), `freshPerRole` from the newest unlocked tier when there are enough, `directors` on a shortlist, `freshDirectors` from the newest director tier |
| `feasibility` | Every playable genre needs a film within budget that makes at least `margin` $M profit; otherwise it shows as too pricey. If no genre makes it, the project seed is salted again, up to `maxResalts` times |
| `pass` | A pass skips the current pitches for `fee` $M. A studio starts with `start` passes and earns one every `every` films, holding at most `cap` |
| `levels` | Lifetime box office ($M, every film counts) needed for each studio level, starting with level 1 at 0. Each level after the first gives one upgrade point. Keep at least as many levels as the upgrades cost in total |
| `upgrades` | Bought with points: `id` (fixed; the page and server key their effect on it), `name`, `cost` in points per rank, `ranks` (one line of text per rank; the number of lines is the max rank), optional `minLevel`. `talent` and `windows` list the fee and marketing discount for each rank (Reputation, Marketing Deals); the other upgrades reveal information on hidden-number projects |

Tuning tips: the ladder sets the pace (the simulation reports films to each step for random and decent play). Caps set how big films can get at each tier. `start.bank` and `start.floor` must cover the cheapest D-list film (about $54M to $62M) plus the margin, or the first projects have no playable genre.

### achievements.json

| Field | Meaning |
| --- | --- |
| `gates` | One entry per ladder step (same `id`): the name and text shown on the HQ and in the unlock moment |
| `badges` | `id` (fixed; the server's rule for each badge is keyed on it), `name`, `text`, and the numbers the rule uses: `blockbuster.profit`, `sleeper_hit.profit` and `costShare`, `genre_master.films` and `bonus` (the gross boost in that genre), `full_house.tier` and `after` |

Badges are earned once and stored with a timestamp. Genre Master also adds its `bonus` to every later film in that genre (the server applies it as a multiplier step in the scoring).
